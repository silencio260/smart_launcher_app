# Launcher OS Icon Drafts V2

Revised app-icon directions for Smart Launcher after reviewing Android launcher listings on Google Play. These aim to read more like a launcher / OS surface than a generic smart-app logo.

## Design Notes

- Simple adaptive-icon silhouettes that survive small launcher sizes.
- Home screen replacement cues: app grid, dock, pages, and search/app-drawer surfaces.
- Material You style color blocks without copying any existing launcher mark.
- Less literal house/shield artwork; more OS icon language.

## Drafts

1. `01-os-home-surface.svg` - home surface with grid and dock.
2. `02-adaptive-launcher-cells.svg` - adaptive launcher cells forming a clean OS mark.
3. `03-drawer-search-core.svg` - app drawer grid with search pulse.
4. `04-page-stack-dock.svg` - layered home pages and bottom dock.
5. `05-category-orbit.svg` - organized launcher categories around a core.
6. `06-themed-launcher-glyph.svg` - simple themed-icon friendly launcher glyph.

Use the SVG files as editable masters. PNG previews and `launcher-os-icon-drafts-v2-contact-sheet.png` are generated from them.
