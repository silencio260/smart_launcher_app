# Smart Launcher Individual Promo Mockups - V2 Play Reference Style

Generated with the built-in image generation tool after using these Play Store listings as visual references:

- `https://play.google.com/store/apps/details?id=ginlemon.flowerfree`
- `https://play.google.com/store/apps/details?id=com.smart.phonelauncher.os.style`

## Direction

- Dark premium launcher promo cards.
- Large vertical phone mockups as the primary subject.
- Short, readable headline and supporting copy.
- Warm GenRevibes orange accent glows and icon details.
- Generated Smart Launcher-style UI only. No supplied screenshots were pasted into these images.
- Closer to launcher Play Store screenshots than the previous white/orange ad-card set.
