# Smart Launcher Logo Replacement Drafts

Six first-pass logo directions for replacing the current default app icon. The SVG files are editable masters sized at `1024x1024` for app-store and launcher-icon export workflows.

## Drafts

1. `01-smart-grid-mark.svg` - launcher grid, home cue, and smart highlight.
2. `02-search-orbit-mark.svg` - search-first launcher identity with orbital motion.
3. `03-private-home-mark.svg` - home screen plus shield for privacy tools.
4. `04-launch-ribbon-mark.svg` - fast launcher ribbon with an upward action cue.
5. `05-organized-stack-mark.svg` - layered cards and dock dots for organization.
6. `06-vibe-monogram-mark.svg` - abstract Smart Launcher monogram with energy wave.

These are draft directions, not final production app icons. Once a direction is chosen, export foreground/background layers for adaptive Android icons and crop-test at small sizes.
